# ⏺ Replay Buffer

כלי Windows להקלטת buffer רץ - כמו GeForce Instant Replay אבל בלי צורך בכרטיס NVIDIA.

## איך זה עובד

האפליקציה מקליטה את המסך שלך **כל הזמן** בזיכרון.  
כשקורה משהו מגניב במשחק - לוחצים על המקש שהגדרת, והיא שומרת את **ה-X דקות האחרונות** לקובץ MP4.

## הגדרות

| הגדרה | ברירת מחדל |
|-------|------------|
| מקש שמירה | F9 |
| אורך הזיכרון | 5 דקות |
| רזולוציה | עד 1280p |
| FPS | 30 |

## התקנה

1. הורד את `ReplayBuffer.exe` מה-[Releases](../../releases)
2. הפעל **כמנהל מערכת**
3. הגדר מקש ואורך זיכרון
4. לחץ "התחל הקלטה"

## איפה נשמרים הסרטונים

```
C:\Users\<שם משתמש>\Videos\ReplayBuffer\
```

כל קובץ נקרא: `Replay_YYYY-MM-DD_HH-MM-SS.mp4`
